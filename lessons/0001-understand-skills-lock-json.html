Lesson 01 · Repository skills

What is skills-lock.json?

It is a reproducibility manifest: a compact record of which skills are expected, where they came from, and how to recognize their content.

Read one entry

"grill-me": {
  "source": "mattpocock/skills",
  "sourceType": "github",
  "skillPath": "skills/productivity/grill-me/SKILL.md",
  "computedHash": "..."
}

source and skillPath identify the upstream file. computedHash fingerprints its content so drift can be detected.

Keep the layers separate

lock file  →  expected source and identity
skill dir  →  actual installed SKILL.md files
symlinks   →  tool-specific access paths

The lock file does not execute a skill and does not replace its SKILL.md.

Quick check

If skills-lock.json lists a skill but the corresponding installed file is missing, what kind of problem is that?

Answer

An incomplete installation: the manifest and installed skill tree disagree.
