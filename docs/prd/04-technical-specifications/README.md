# 4. Technical Specifications

Technical specifications and technical decisions are maintained outside the
PRD under [`docs/tech`](../../tech/README.md).

- [Technical Specifications](../../tech/technical-specifications/README.md)
- [Technical Decisions](../../tech/decisions/README.md)

The PRD defines product scope and acceptance criteria; `docs/tech` is the
source of truth for architecture, interfaces, security, implementation
constraints, and recorded decisions.
