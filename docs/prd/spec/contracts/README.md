# Behavioral contracts

No shared behavioral contracts have been extracted yet. Keep rules in their
capability until they are shared or need a separate detailed document.

For an extracted contract, record agreement and implementation status, stable
rule IDs, preconditions, observable outcomes, relevant state transitions and
invariants, failure examples, and verification links. Add a link here and from
every capability that relies on it.

Technical schemas and implementation design remain in
[technical specifications](../../../tech/technical-specifications/README.md).
This directory defines product behavior; it links to technical representations.
